Common Data Set

The Common Data Set (CDS) is a data collection tool produced collaboratively by college guide publishers and higher education professionals. The CDS survey was developed to improve the quality of information provided to potential students by making comparable information based on common data definitions available.

The CDS Appendix provides additional information to respond to frequently asked questions about the campus.
