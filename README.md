# College Admissions Library

A private college-counseling research app with 92 seeded Common Data Set reports: Cornell (1999–2025), USC Columbia (2000–2025), Clemson (2008–2025), and Washington and Lee (2005–2025). Includes source-linked Section C text and PDF form answers, normalized admissions counts and rates, waitlists, test percentiles, rank, factor ratings, fees, and historical deadlines where extraction is reliable. Schools imported by counselors remain in the shared database independently of this seed.

## Use

The Schools view shows one latest matching profile per institution, with direct links from its headline figures to supporting source pages. Explore a school's reporting years in the Yearly reports view, switch years inside a profile, select up to four records to compare, or export the visible results/selection to CSV. Search includes all preserved Section C text. Full record downloads preserve evidence and source notes. "Not reported" means no normalized value is available; consult the source. Zero remains zero. Policies may refer to a later admissions cycle than the fall enrollment cohort.

## Data and expansion

Hosted persistence uses Cloudflare D1 SQLite. Reports have a unique institution/year key and indexed institution/year and year lookups. An FTS5 index, maintained by triggers, searches the record content. Both school profiles and yearly reports paginate in the database to 100 results; school grouping uses window functions before pagination. Full source records load on demand.

**Add school data** accepts an official Common Data Set archive webpage or direct PDF URL. It discovers linked PDF reports, lets the user select up to 25 per batch, downloads bounded public sources through the server, and extracts filled form answers and selectable PDF text in the browser with PDF.js. Each draft retains its source URL, SHA-256, physical PDF pages, Section C text, form answers, and per-metric evidence. The review screen supports corrections to counts, scores, factor ratings, policies and deadlines. The user must confirm review and supply the three C1 headline counts before saving. Rates are recalculated from reviewed counts. Existing school/year records require an explicit replacement choice. Reviewed records persist in the shared database; extracting a report alone does not save it.

The importer recognizes common CDS layouts, including modern forms and older text tables. Missing and ambiguous responses stay blank for review. It does not perform OCR, extract spreadsheet or HTML-only reports, bypass school server access restrictions, or crawl an entire university website. Download limits are 25 MB and 200 PDF pages. Use the school's CDS archive rather than its homepage; some scanned or unusual layouts need manual corrections or a separate source adapter. Public-source fetching checks URLs and DNS addresses, checks redirects, bounds response sizes, and never forwards visitor cookies or authorization headers.

JSON remains the structured interchange format for full record downloads and the validated `/api/reports` POST endpoint. `public/import-template.json` documents that format for source adapters and backups; replace its illustrative values and links before use. Counts must be nonnegative integers; percentages must be 0–100; each record requires an HTTP or HTTPS source and source text. Private site access is enforced by Sites; preserve owner-private access until an appropriate sharing policy is configured. The importer is a shared-library write operation behind that access boundary.

`data/reports.json` is the reproducible seed. `data/admissions.sqlite` is a portable SQLite copy, generated by verification (it is not the hosted runtime database). `data/sources/` caches original official PDFs/spreadsheets and extraction evidence with SHA-256 provenance.

Re-extract Cornell locally:

```powershell
python -m pip install -r scripts/requirements.txt
python scripts/ingest_cornell.py
python scripts/normalize.py
python scripts/verify_data.py
```

The Fall 2022 linked PDF contains only Section B; normalization uses the official companion `CDS-C` spreadsheet. The 2023 PDF/spreadsheet leave several policy fields, including factor ratings, blank. Historical score scales differ, and SAT reading/math percentiles are never added to invent a composite score. All headline counts have consistency and source checks, and form-field counts are independently reconciled. This is an extracted research library, not a claim that every response has been manually audited.

For another institution, start with the website importer. For sources outside its supported layouts, a source adapter can output the same report JSON for the validated API. Verify values against original pages in either case.

Every school added through the assistant is also an opportunity to improve the shared importer. Inspect the school's source layouts, implement reusable rules for reliably recognized patterns, and add regression checks against verified source values. Use scoped adapters for exceptional formats and document any remaining manual steps. Improvements to the hosted importer benefit subsequent website imports after publication. The standing workflow and data-integrity requirements are recorded in `AGENTS.md`; manual corrections to an individual report remain separate from parser support.

South Carolina's historical document server uses HTTP; links preserve the working official URLs. PDF records link to physical pages; HTML records link directly to the official Section C page. Unreported SAT composites are left blank. Cached sources and normalized evidence are stored in `data/sources/south-carolina-*`.

The **Trends** tab starts with Cornell admission rates for fall 2010–2015. It supports admission rate, applications, enrollment, and yield, any imported school, a comparison school, and calendar-year gaps. Rates are calculated from counts before display rounding. Each point and table value links to its original source. PNG/SVG exports include a title, legend, year range, definition, and institutional attribution; SVG also retains source hyperlinks and metadata. CSV includes counts and annual source links. No access changes are needed to download a chart for sharing.

`node scripts/check-trends.mjs` checks known counts/rates, comparisons, source links, downloaded artifacts, keyboard point details, missing-year gaps, single-year and invalid ranges, and mobile layout.

`check-website-import.mjs` checks original Cornell and USC form/text PDFs against verified counts, scores and factor ratings, rejects Cornell's Section B-only PDF, and exercises review, corrections, replacement protection, source provenance, the save payload and mobile layout without modifying the database. `check-source-fetch.mjs` checks public URL/DNS restrictions, redirects, size limits, credentials and year parsing. `run-framework.mjs` copies the exact installed PDF.js worker to the build's public assets before development/build.

C1 extraction recognizes men/women and male/female labels, includes reported unknown-sex counts, and reconciles recognized overall, gender and residency totals. Residency tables with an explicit Total column are distinguished from tables containing only residency components. A single recognized gender count is never treated as a cohort total. Conflicting totals leave the headline metric blank and require source review. `node scripts/check-c1-counts.mjs` covers these cases; `node scripts/check-wlu-import.mjs` verifies the original W&L 2025 PDF against its gender and residency totals (8,963 applicants, 1,214 admits, 499 enrolled). Updating extraction does not retroactively repair previously saved imports.

`data/archive-sources.json` records the original archive links, working source-file URLs, cached paths, and SHA-256 values. W&L files came from its official server. Clemson's current download server rejected requests, so its school-issued reports were recovered from public archival copies: older official files in the Internet Archive and newer files preserved by CollegeData.fyi or a public CommonDataSets repository. The 2021 source is an XLSX workbook; the 2025 PDF requires local OCR and visually reviewed overrides. This adapter does not add OCR to the browser importer. C1 totals are recorded in `data/archive-c1-review.json`; source discrepancies and stale labels are disclosed in each report. Unrecognized factor marks remain blank. Remaining extracted fields retain source evidence and should be reviewed before use.

Preparing the seed preserves an existing corrected W&L 2025 record from an optional local shared-database snapshot, or from the seed on subsequent runs. Live imports add missing school/year records and leave existing counselor records intact. Source discovery now respects HTML base URLs and accessible PDF link labels.

Profiles also support residency admissions, ED share, GPA averages and separately labeled GPA populations, SAT/ACT score bands, coursework, early-action policies, annual costs, first-year aid, retention, four/six-year graduation, undergraduate class sections, student/faculty ratios, and transfer admissions. Additional source pages are retained separately from the original Section C text. Reporting years and entering cohorts remain explicit. Missing, ambiguous, scanned-only, and unsupported responses remain unreported.

Trends includes SAT/ACT percentile ranges, reported medians, annual application growth, percentage-point admission-rate changes, five consecutive years' average rates, and the new numeric measures. SAT range charts show the 25th–75th interval and a median dot only when the source reports one; section percentiles are never added to invent a composite. Historical tests/scales require care when comparing years. Profiles show source-linked score-band and GPA-distribution bars. PNG/SVG/CSV downloads remain available.

`node scripts/check-additional-metrics.mjs` checks independently verified source fixtures across six reports, including blank GPA checkers, distinct submitter populations, aid denominators, split class labels, graduation cohorts, historical tables, reporting units, and missing-year trend calculations. `node scripts/check-metrics-ui.mjs` checks the added profile tabs, SAT comparisons, real/missing medians, exports, and mobile overflow. `python scripts/cache_full_reports.py` and `node scripts/enrich_saved_reports.mjs` prepare additive enrichment candidates; they preserve existing metrics and do not write to the hosted database. The optional ignored shared snapshot also covers counselor-imported schools. Historical Section C-only webpages/workbooks and scanned PDFs can have fewer normalized metrics than full selectable-text reports. Browser imports now use the same extended parser and let counselors edit the new source fields before saving.

NYU coverage includes eight reports for Fall 2018–2025. NYU's public server returned 403 during collection, so these NYU-authored reports use exact archived copies from CollegeData.fyi, with working file links and SHA-256 hashes in `data/nyu-sources.json`. `data/nyu-source-review.json` records independently checked C1 counts, test percentiles, and publisher discrepancies: 2019 repeats Fall 2018 in C1; 2022 has an older template header; 2023 includes another gender and zero formula cells in an otherwise blank residency table. Reviewed cohort corrections are separate from extraction rules. Costs and policy years can differ from the admission cohort; missing sections are not borrowed from other years.

Run `python scripts/collect_nyu.py`, then `node scripts/import_nyu.mjs` to prepare the records. The importer adds missing seed records and preserves existing records. The 2021/2025 workbook adapter retains worksheet cell references, formats percentage cells, and excludes the appended answer dictionary from printed rows. This remains an offline adapter; the website accepts PDF extraction and reviewed JSON imports. Source worksheet numbers are not physical PDF pages.

The shared browser parser now reconciles merged full-time/gender-total rows against part-time counts, reads complete gender-column tables with whole-number decimal formatting, and rejects unreconciled partial counts and ambiguous zero totals. It also supports wrapped factor labels, text ratings and documented label aliases, wrapped reading-score labels, explicitly labeled SAT/ACT submitter counts, reported text dates, and wrapped GPA answers. Missing optional gender cells can corroborate an independently verified equal total without being assumed zero. `node scripts/check-nyu-import.mjs` checks retained geometry fixtures and ambiguity cases; `node scripts/check-nyu-browser.mjs` checks all six actual PDFs through the website's PDF.js pipeline and the NYU library/trend/export views. Existing C1, W&L, website import, and additional-metric checks remain applicable.

The trend metric picker groups measures into Admissions, Test scores, Academic profile, Costs & financial aid, Student outcomes, and Transfer admissions. Each group has a labeled color marker and alphabetically sorted metrics; search matches metric names or category labels and supports keyboard selection. `lib/metric-groups.ts` keeps category assignment separate from labels and plot units.

Trend legends use school marks and readable school colors consistently across years, line charts, SAT ranges, tooltips, and PNG/SVG exports. Comparisons also use dashed lines and diamond markers. `data/school-branding.json` records aliases, published color references, and official website mark provenance; files under `public/school-marks` are bundled locally. Clemson uses the published darker Campus Brick orange for text/plots. New schools get a stable color and initials until branding is registered. SVG exports embed logo bytes rather than depending on external image URLs; unavailable images fall back to initials. No admissions records or access policies are changed by branding. `node scripts/check-trend-branding.mjs` verifies grouping, sorting, search, keyboard/focus behavior, colors, logos, image exports, future-school fallback, and mobile layout using read-only fixtures.
